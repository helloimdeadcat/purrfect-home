# Purrfect Home — что сделать дома

Пошаговая инструкция: от распаковки архива до полностью рабочего приложения.
Подробная техническая документация — в `AI_HANDOFF.md` и `README.md`.

---

## 0. Что в архиве

- `family-finance/` — весь проект (без `node_modules` и `.next`, они ставятся/собираются заново).
- `family-finance/.env.local` — ключи Supabase. **Секретный файл:** не выкладывать в git и никому не пересылать.
- `План_питания_на_7_дней.pdf` — исходный план питания (уже перенесён в код).

---

## 1. Распаковать и установить

Нужен Node.js 20+ (проверить: `node -v`).

```bash
tar -xzf purrfect-home-2026-10-26.tar.gz
cd family-finance
npm install --legacy-peer-deps
```

`--legacy-peer-deps` обязателен (у recharts устаревшие peer-зависимости).

---

## 2. Применить миграции базы (обязательно, один раз)

На удалённом Supabase сейчас только миграции 1–8. Новые функции (настройки,
уведомления, дела, привычки, питание и т.д.) работают только после миграций 9–16.

1. Открыть https://supabase.com/dashboard → свой проект → **SQL Editor** → **New query**.
2. Открыть файл `supabase/pending/apply-pending-migrations.sql`, скопировать **весь** текст, вставить, нажать **Run**.
3. Внизу появится таблица-чек-лист: **во всех строках `ok = true`**.
   - Если где-то `false` или ошибка — ничего не трогать, сохранить текст ошибки и прислать мне.
   - Повторный запуск безопасен (все миграции идемпотентны).
4. Проверить с компьютера:
   ```bash
   npm run check:remote
   ```
   Все пункты должны быть отмечены как OK.

---

## 3. Подключить ИИ-помощника (Gemini, бесплатно)

1. Зайти на https://aistudio.google.com/apikey под Google-аккаунтом → **Create API key** → скопировать.
2. Открыть `.env.local` и дописать в конец:
   ```
   AI_API_KEY=сюда-ключ
   ```
3. Если потом Google ответит, что модель недоступна, добавить ещё строку:
   ```
   AI_MODEL=gemini-2.5-flash
   ```
   (по умолчанию стоит `gemini-flash-latest`).

Без ключа всё остальное работает, а страница Assistant просто показывает подсказку.

Важно: вопросы и данные, которые помощник смотрит (еда, дела, привычки, балансы),
уходят в Google; на бесплатном тарифе Google может использовать их для улучшения
своих моделей.

## 4. Запустить

```bash
npm run dev
```

Открыть http://localhost:3000, войти.

Перед этим (необязательно, но полезно) прогнать проверки:

```bash
npm test          # ~280 тестов, все должны пройти
npm run build     # продакшн-сборка без ошибок
```

## 5. Первая настройка в приложении

1. **Family** — убедиться, что в семье оба партнёра (если второго нет — отправить приглашение).
2. **Meals** → кнопка импорта плана → выбрать, кто «Муж», а кто «Жена» → импорт.
   Подтянутся 30 продуктов, 28 приёмов пищи с граммовками, цели по КБЖУ и привычки
   (вода, шаги, силовая).
3. **Habits** — проверить импортированные привычки, при желании добавить свои.
4. **To-do / Schedule** — создать пару дел, назначить на каждого и «вместе», сделать одно повторяющимся.
5. **Settings** — проверить часовой пояс семьи (от него зависит, какой день считается «сегодня»).

## 6. Проверка после запуска (чек-лист)

Пройтись и отметить; если что-то не так — скриншот + что делал, прислать мне.

**Общее**
- [ ] Вход/выход работают, меню на телефоне (узкое окно) не ломается.
- [ ] Сердечко уведомлений в шапке открывает список уведомлений.

**Деньги**
- [ ] Dashboard открывается без ошибок, видны балансы и Safe-to-Spend.
- [ ] Добавить транзакцию, прикрепить фото чека, удалить чек.
- [ ] Budgets / Goals / Recurring / Calendar / Analytics открываются.
- [ ] Экспорт CSV скачивает файл.

**Дела и расписание**
- [ ] Создать дело на сегодня для партнёра → у партнёра появилось уведомление.
- [ ] Повторяющееся дело (например, по пн и чт) правильно показывается в Schedule.
- [ ] Отметить выполненным / снять отметку.
- [ ] На Dashboard видна карточка «Today together».

**Привычки**
- [ ] Отметить привычку за сегодня; степпер −/+ для «воды».
- [ ] Отметить можно только себя, не дальше 7 дней назад.

**Питание**
- [ ] Today показывает приёмы на сегодня и итоги КБЖУ против целей.
- [ ] Week plan: изменить граммы, переименовать блюдо — сохраняется.
- [ ] Shopping → «Add to To-do» создаёт дело со списком покупок.

**Помощник**
- [ ] Assistant ✨: спросить «Что у нас сегодня по плану?» — ответ по реальным данным.
- [ ] На карточке приёма пищи нажать «✨ Recipe idea» — приходит рецепт.
- [ ] Попросить «Добавь дело купить молоко на завтра для меня» → появляется карточка → **Apply** → дело появилось в To-do.
- [ ] Dismiss ничего не меняет.

**PWA (телефон)**
- [ ] В браузере телефона «Добавить на главный экран» — появляется иконка с котиком.

## 8. Потом, перед «боевым» использованием

- **Перевыпустить ключи Supabase** (anon и service_role) в Settings → API и обновить `.env.local`:
  старые ключи лежали в архивах и переписке.
- Заодно перевыпустить ключ Gemini, если он где-то светился.
- **Supabase лимиты (Фаза 5):** в дашборде посмотреть тариф и использование
  (база, Storage для чеков, Auth) — чтобы бесплатный план не упёрся в лимиты.
- При деплое (например, Vercel) задать те же переменные окружения, плюс
  `APP_URL=https://твой-адрес` — чтобы ссылки-приглашения были правильными.
  `SUPABASE_SERVICE_ROLE_KEY` и `AI_API_KEY` — только серверные, никогда не с префиксом `NEXT_PUBLIC_`.

## 9. Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| `npm install` ругается на peer deps | Запускать с `--legacy-peer-deps` |
| Страницы Habits/Meals/To-do пустые или с ошибкой про таблицу | Не применены миграции — шаг 2 |
| `check:remote` показывает FAIL | Прислать мне вывод целиком |
| Assistant: «isn't set up yet» | Нет `AI_API_KEY` в `.env.local` или не перезапущен `npm run dev` |
| Assistant: ошибка 429 / «a lot of questions» | Лимит: 20 вопросов за 10 минут или лимит бесплатного Gemini — подождать |
| Assistant: ошибка модели | Добавить `AI_MODEL=gemini-2.5-flash` и перезапустить |
| На телефоне старая версия страницы | Закрыть и открыть приложение / обновить страницу (кэш PWA) |
